# ML Assignment 2 — Classification Model Comparison

## a. Problem statement

Train five classification models on one public dataset, compare their predictive
performance with six required metrics, and provide an interactive Streamlit
application that evaluates saved models against labeled test data without
retraining.

The positive class is **malignant**. Precision, recall, and F1 therefore measure
performance on malignant cases. AUC uses the malignant-class probability where
available and the decision score for the SVM.

## b. Dataset description

This project uses the **Wisconsin Diagnostic Breast Cancer (WDBC)** dataset from
the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic).
The scikit-learn packaged copy contains 569 records, 30 numeric features, and two
diagnosis classes (malignant and benign), satisfying the minimum size requirements.
Features describe characteristics of cell nuclei measured from digitized images.

The script reserves a stratified 20% holdout set using random seed 42. Every model
uses the same training and test rows. Scaling is applied to Logistic Regression,
KNN, and SVM; the tree and Gaussian Naive Bayes models do not require scaling.
The uploaded CSV is test data only and is never used for fitting.

### Observations on model performance

Metrics are from the fixed 114-row holdout set. Compare malignant recall as well
as overall accuracy: missing a malignant case has a different practical cost
than a benign false alarm.

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Strong overall separation (AUC 0.9960) and malignant recall of 0.9286; it misses 3 malignant cases and has 1 benign case flagged as malignant. |
| Decision Tree | The weakest overall holdout result (accuracy 0.9298, AUC 0.9246); its recall is 0.9048, with 4 missed malignant cases and 4 benign false alarms. |
| K-Nearest Neighbors | Good accuracy (0.9561) and AUC (0.9823), but malignant recall (0.9048) is lower than Logistic Regression and SVM; it misses 4 malignant cases and has 1 benign false alarm. |
| Gaussian Naive Bayes | No benign false alarms (precision 1.0000), but the lowest malignant recall (0.8333); it misses 7 malignant cases. |
| Support Vector Machine | Best accuracy (0.9737), F1 (0.9630), and MCC (0.9442); precision is 1.0000 and malignant recall is 0.9286, so it misses 3 malignant cases. |
| Overall winner for this dataset | Support Vector Machine is the best balanced choice by accuracy, F1, and MCC. Logistic Regression has the highest AUC (0.9960); selection could differ if ranking quality is the priority. |

## Run locally

```bash
python -m pip install -r requirements.txt
python train_models.py
streamlit run app.py
```

In the app, upload `test_data.csv`. It presents metrics for all five models and
a confusion matrix plus classification report for the selected model. CSV files
must include all 30 feature columns and `diagnosis`; diagnosis values must be
`malignant` or `benign`.
